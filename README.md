# ACCORDO — Tu camino musical

Plataforma web pensada para conectar a niños y jóvenes que buscan acceder a formación e instrumentos musicales en Panamá con personas, comunidades, academias y fundaciones que pueden alquilar, vender o donar instrumentos y recursos.

## Propósito del proyecto

Muchas veces niños y jóvenes quieren aprender música, pero no logran conseguir un instrumento por falta de oportunidades claras o porque comprar uno nuevo es muy costoso. Al mismo tiempo, hay personas que tienen instrumentos guardados en casa sin usar y no saben qué hacer con ellos: a veces los empeñan o los entregan sin un destino claro.

**ACCORDO** nace para unir ambos lados y dar opciones concretas: quienes tienen un instrumento o recurso pueden decidir si **alquilar**, **vender** o **donar** —incluyendo el apoyo hacia **Provincias Centrales**, **fundaciones** o **personas que entran a la plataforma buscando un instrumento**. Es un espacio que reúne lo necesario para acompañar el proceso musical de principio a fin.

## ¿Qué reúne la plataforma?

* **Catálogo de instrumentos, libros, partituras y accesorios:** Opciones de venta, alquiler y donación, con guías de tallas (incluyendo medidas específicas por instrumento, como pulgadas en viola) para orientar mejor cada elección.
* **Módulos de estudio y ruta de aprendizaje:** Recursos y orientación para avanzar paso a paso.
* **Red de academias, fundaciones y profesores:** Información para ubicar espacios de formación musical.
* **Donaciones y voluntariado:** Canales informativos para apoyar con aportes o colaboración en áreas técnicas y comunitarias.

## Tecnologías utilizadas

* **Frontend:** React, TypeScript, HTML5, CSS3 / Tailwind CSS
* **Herramientas de desarrollo y flujo:** Vite, Visual Studio Code, Git / GitHub

## Estado del proyecto

Proyecto en desarrollo y demostración, enfocado en acercar recursos y oportunidades musicales a más estudiantes.
